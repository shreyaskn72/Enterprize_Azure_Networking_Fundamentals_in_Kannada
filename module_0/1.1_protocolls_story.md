ನಮ್ಮ ರಾಮು ಮತ್ತು ಸೋಮುನ ಮಹಾ ಕಥೆಯನ್ನು ಕೊನೆಯ ಭಾಗಕ್ಕೆ ಕೊಂಡೊಯ್ಯೋಣ! ಈಗ ಪತ್ರಗಳು ಸರಿಯಾದ ಮನೆ ಮತ್ತು ಕಿಟಕಿ (Port) ತಲುಪಲು ಎಲ್ಲ ಸಿದ್ಧತೆಯಾಗಿದೆ. ಆದರೆ, ಪತ್ರವನ್ನು ಹೇಗೆ ಕಳುಹಿಸಬೇಕು, ದಾರಿಯಲ್ಲಿ ಅದು ಕಳೆದುಹೋದರೆ ಯಾರು ಜವಾಬ್ದಾರಿ, ಮತ್ತು ರಹಸ್ಯ ಮಾಹಿತಿಯನ್ನು ಕಳ್ಳರು ಓದದಂತೆ ಹೇಗೆ ತಡೆಯುವುದು?
ಇಲ್ಲಿಗೇ ಎಂಟ್ರಿ ಕೊಡುವುದು ಪ್ರೋಟೋಕಾಲ್‌ಗಳು (Protocols) ಅಂದರೆ "ನಿಯಮಗಳು". ಇವುಗಳನ್ನು ಇಬ್ಬರು ಅಂಗರಕ್ಷಕರು (TCP & UDP) ಮತ್ತು ಇಬ್ಬರು ಸಂದೇಶವಾಹಕರ (HTTP & HTTPS) ಕಥೆಯ ಮೂಲಕ ತಿಳಿಯೋಣ.
------------------------------
## ೧. ಇಬ್ಬರು ಅಂಗರಕ್ಷಕರು: TCP ಮತ್ತು UDP (Transport Layer)
ರಾಮು ಬೆಂಗಳೂರಿನಲ್ಲಿರುವ ಸೋಮುಗೆ ಪತ್ರ ಕಳುಹಿಸುವಾಗ, ಪಿಜಿ ಬಾಗಿಲಿನವರೆಗೆ ಪತ್ರವನ್ನು ಸುರಕ್ಷಿತವಾಗಿ ತಲುಪಿಸಲು ಇಬ್ಬರು ವಿಭಿನ್ನ ಸ್ವಭಾವದ ಅಂಗರಕ್ಷಕರನ್ನು (Bodyguards) ಕೆಲಸಕ್ಕೆ ಇಟ್ಟುಕೊಳ್ಳಬಹುದು:
## ಎ) ಜವಾಬ್ದಾರಿಯುತ ಅಂಗರಕ್ಷಕ: TCP (Transmission Control Protocol)
ಇವನು ತುಂಬಾ ಶಿಸ್ತು ಮತ್ತು ಜವಾಬ್ದಾರಿ ಇರುವ ಅಂಗರಕ್ಷಕ.

* ಕೆಲಸದ ಶೈಲಿ: ರಾಮು ಪತ್ರ ಕೊಡುವ ಮುನ್ನ, ಇವನು ಮೊದಲು ಬೆಂಗಳೂರಿಗೆ ಓಡಿಹೋಗಿ ಸೋಮುನ ಕೈ ಕುಲುಕಿ "ನಾವು ಪತ್ರ ಕಳುಹಿಸುತ್ತಿದ್ದೇವೆ, ನೀನು ಸಿದ್ಧನಿದ್ದೀಯಾ?" ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳುತ್ತಾನೆ (ಇದನ್ನು ನೆಟ್‌ವರ್ಕಿಂಗ್‌ನಲ್ಲಿ 3-Way Handshake ಎನ್ನುತ್ತಾರೆ).
* ಸೋಮು "ಹೌದು" ಅಂದಮೇಲಷ್ಟೇ ಪತ್ರದ ಪ್ರಯಾಣ ಶುರುವಾಗುತ್ತದೆ. ಇವನು ಪ್ರತಿ ಪುಟವನ್ನು ಸೋಮುನಿಗೆ ತಲುಪಿಸಿ, ಸೋಮುನಿಂದ "೧ನೇ ಪುಟ ಸಿಕ್ಕಿತು", "೨ನೇ ಪುಟ ಸಿಕ್ಕಿತು" ಎಂದು ಫೋನ್ ಮುಖಾಂತರ ಒಪ್ಪಿಗೆ ಪತ್ರವನ್ನು (Acknowledgment) ಪಡೆದುಕೊಳ್ಳುತ್ತಾನೆ.
* ಒಂದು ವೇಳೆ ದಾರಿಯಲ್ಲಿ ೩ನೇ ಪುಟ ಮಳೆಗೆ ಕೊಚ್ಚಿಹೋದರೆ, ಇವನು ಬಿಡುವುದಿಲ್ಲ; ವಾಪಸ್ ಹಳ್ಳಿಗೆ ಬಂದು ರಾಮುನಿಂದ ೩ನೇ ಪುಟವನ್ನು ಮತ್ತೊಮ್ಮೆ ಬರೆಸಿಕೊಂಡು ಹೋಗಿ ಸೋಮುಗೆ ತಲುಪಿಸುತ್ತಾನೆ. ಡೇಟಾ ೧% ಕೂಡ ಕಳೆದುಹೋಗದಂತೆ ಗ್ಯಾರಂಟಿ ನೀಡುತ್ತಾನೆ.
* ಬಳಕೆ: ನಿಮ್ಮ ಮುಖ್ಯ ಇಮೇಲ್‌ಗಳು, ವೆಬ್‌ಸೈಟ್‌ಗಳು ಮತ್ತು ಫೈಲ್ ವರ್ಗಾವಣೆಗಳಿಗೆ ಈ TCP ಅಂಗರಕ್ಷಕನೇ ಬೇಕು.

## ಬಿ) ಅತಿ ವೇಗದ ಅಂಗರಕ್ಷಕ: UDP (User Datagram Protocol)
ಇವನಿಗೆ ಜವಾಬ್ದಾರಿಗಿಂತ "ವೇಗ" ಮುಖ್ಯ. ಇವನು ತುಂಬಾ ಧಾವಂತದ ಹುಡುಗ.

* ಕೆಲಸದ ಶೈಲಿ: ಇವನು ಸೋಮುನಿಗೆ ಫೋನ್ ಮಾಡುವುದಿಲ್ಲ, ಕೈ ಕುಲುಕುವುದಿಲ್ಲ. ರಾಮು ಪತ್ರ ಕೊಟ್ಟ ತಕ್ಷಣ ಬೆಂಗಳೂರಿನ ಕಡೆಗೆ ವೇಗವಾಗಿ ಓಡುತ್ತಾನೆ. ದಾರಿಯಲ್ಲಿ ಪತ್ರಗಳು ಬಿದ್ದರೂ ಇವನು ತಿರುಗಿ ನೋಡುವುದಿಲ್ಲ, ವಾಪಸ್ ಬಂದು ರಾಮುಗೆ ಹೇಳುವುದೂ ಇಲ್ಲ. ಸೋಮುಗೆ ಪತ್ರ ಸಿಕ್ಕಿತೋ ಇಲ್ಲವೋ ಇವನಿಗೆ ಅನಗತ್ಯ. ಇವನಿಗೆ ಬೇಕಿರುವುದು ಕೇವಲ ವೇಗವಾಗಿ ತಲುಪಿಸುವುದು ಅಷ್ಟೇ.
* ಬಳಕೆ: ನಾವು ಆನ್‌ಲೈನ್‌ನಲ್ಲಿ ಲೈವ್ ವಿಡಿಯೋ ನೋಡುವಾಗ (Video Streaming) ಅಥವಾ ಫೋನ್‌ನಲ್ಲಿ ಇಂಟರ್ನೆಟ್ ಕರೆ ಮಾತಾಡುವಾಗ (VoIP), ಒಂದು ಸೆಕೆಂಡ್ ಧ್ವನಿ ಕಟ್ ಆದರೂ ಪರವಾಗಿಲ್ಲ, ಆದರೆ ಮಾತು ಲೈವ್ ಆಗಿ ಕೇಳಿಸಬೇಕು. ಅಲ್ಲಿ ಈ UDP ವೇಗದ ಅಂಗರಕ್ಷಕ ಕೆಲಸ ಮಾಡುತ್ತಾನೆ.

------------------------------
## ೨. ಇಬ್ಬರು ಸಂದೇಶವಾಹಕರು: HTTP ಮತ್ತು HTTPS (Application Layer)
ಈಗ ಸೋಮುನ ದೊಡ್ಡಣ್ಣನ ವಿಷಯಕ್ಕೆ ಬರೋಣ. ನೆನಪಿಸಿಕೊಳ್ಳಿ, ದೊಡ್ಡಣ್ಣನಿಗೆ ಕಥೆ ಪುಸ್ತಕಗಳನ್ನು ಓದುವ ಹವ್ಯಾಸ (Web Browsing). ಇವನು ಹಳ್ಳಿಯ ಲೈಬ್ರರಿಯಿಂದ ಕಥೆಗಳನ್ನು ತರಿಸಿಕೊಳ್ಳಲು ಇಬ್ಬರು ವಿಶೇಷ ಸಂದೇಶವಾಹಕರನ್ನು (Messengers) ಬಳಸುತ್ತಾನೆ:
## ಎ) ಮುಗ್ಧ ಸಂದೇಶವಾಹಕ: HTTP (Hypertext Transfer Protocol)
ಇವನು ಹಳೆಯ ಕಾಲದ ಮುಗ್ಧ ಸಂದೇಶವಾಹಕ.

* ಕೆಲಸದ ಶೈಲಿ: ದೊಡ್ಡಣ್ಣ ಲೈಬ್ರರಿಗೆ "ನನಗೆ ಒಂದು ಕಥೆ ಪುಸ್ತಕ ಬೇಕು" ಎಂದು ಪತ್ರ ಬರೆದಾಗ, ಇವನು ಆ ಪತ್ರವನ್ನು ಕವರಿನೊಳಗೆ ಇಡದೆ ಬರಿಗಣ್ಣಿಗೆ ಕಾಣುವಂತೆ ಕೈಯಲ್ಲೇ ಹಿಡಿದುಕೊಂಡು ಹೋಗುತ್ತಾನೆ. ದಾರಿಯಲ್ಲಿ ಯಾರು ಬೇಕಾದರೂ ಆ ಪತ್ರವನ್ನು ಓದಬಹುದು (ಇದನ್ನು Plain Text ಎನ್ನುತ್ತಾರೆ).
* ಒಂದು ವೇಳೆ ದೊಡ್ಡಣ್ಣ ತನ್ನ ಬ್ಯಾಂಕ್ ರಹಸ್ಯ ಸಂಖ್ಯೆ ಅಥವಾ ಪಾಸ್‌ವರ್ಡ್ ಅನ್ನು ಇವನ ಕೈಯಲ್ಲಿ ಕೊಟ್ಟು ಕಳುಹಿಸಿದರೆ, ದಾರಿಯಲ್ಲಿ ನಿಂತಿರುವ ಕಳ್ಳರು ಅದನ್ನು ಸುಲಭವಾಗಿ ನೋಡಿ ಕದಿಯಬಹುದು. ಇದು ತುಂಬಾ ಅಪಾಯಕಾರಿ! (ಅದಕ್ಕೇ ಇವನ ಕಿಟಕಿ ಸಂಖ್ಯೆ ಅಥವಾ ಪೋರ್ಟ್ 80).

## ಬಿ) ರಹಸ್ಯ ಸೈನಿಕ: HTTPS (Hypertext Transfer Protocol Secure)
ಇವನು ಆಧುನಿಕ ಜಗತ್ತಿನ ರಹಸ್ಯ ರಕ್ಷಣಾ ಸೈನಿಕ. HTTP ನ ಕೊನೆಯಲ್ಲಿ ಇರುವ 'S' ಎಂದರೆ Secure (ಸುರಕ್ಷಿತ).

* ಕೆಲಸದ ಶೈಲಿ: ದೊಡ್ಡಣ್ಣ ಇವನಿಗೆ ಪತ್ರ ಕೊಟ್ಟ ತಕ್ಷಣ, ಇವನು ಆ ಪತ್ರಕ್ಕೆ ಒಂದು ರಹಸ್ಯ ಬೀಗ ಹಾಕುತ್ತಾನೆ (ಇದನ್ನು Encryption / SSL-TLS ಎನ್ನುತ್ತಾರೆ). ಆ ಪತ್ರದಲ್ಲಿ ಏನಿದೆ ಎಂದು ಲೈಬ್ರರಿ ಮಾಲೀಕನಿಗೆ ಮಾತ್ರ ಓದಲು ಸಾಧ್ಯ, ಜಗತ್ತಿನ ಬೇರೆ ಯಾರಿಗೂ ಸಾಧ್ಯವಿಲ್ಲ.
* ದಾರಿಯಲ್ಲಿ ಕಳ್ಳರು ಆ ಪತ್ರವನ್ನು ಕದ್ದರೂ, ಅದರ ಮೇಲಿರುವ ಮಾಂತ್ರಿಕ ಭಾಷೆ ಅಥವಾ ರಹಸ್ಯ ಕೋಡ್ ಅವರಿಗೆ ಅರ್ಥವಾಗುವುದೇ ಇಲ್ಲ. ಇವನು ಸಂಪೂರ್ಣ ಸುರಕ್ಷತೆಯನ್ನು ಒದಗಿಸುತ್ತಾನೆ. (ಇವನ ವಿಶೇಷ ಕಿಟಕಿ ಸಂಖ್ಯೆ ಅಥವಾ ಪೋರ್ಟ್ 443).
* ಬಳಕೆ: ಇಂದು ನಾವು ಬಳಸುವ ಗೂಗಲ್, ಫೇಸ್‌ಬುಕ್, ಮತ್ತು ಬ್ಯಾಂಕಿಂಗ್ ವೆಬ್‌ಸೈಟ್‌ಗಳೆಲ್ಲವೂ ಈ HTTPS ಸೈನಿಕನನ್ನೇ ಬಳಸುತ್ತವೆ.

------------------------------
## ಮಹಾ ಕಥೆಯ ಅಂತಿಮ ಸಾರಾಂಶ (The Complete Map so far)
ರಾಮು ಬರೆದ ಪತ್ರಕ್ಕೆ (Packet) ಮೊದಲು HTTPS ಸೈನಿಕ ರಹಸ್ಯ ಕೋಡ್ ಬರೆಯುತ್ತಾನೆ. ನಂತರ ಜವಾಬ್ದಾರಿಯುತ TCP ಅಂಗರಕ್ಷಕ ಅದನ್ನು ಜಾಗರೂಕತೆಯಿಂದ ಹಿಡಿದುಕೊಳ್ಳುತ್ತಾನೆ. ಅದಕ್ಕೊಂದು ಕವರ್ ಹಾಕಿ ಸೀಲ್ ಮಾಡಿ (Frame), Routing ದಾರಿಯ ಮೂಲಕ, IP Address ಹುಡುಕಿಕೊಂಡು, Firewall ಗಾರ್ಡ್‌ನ ತಪಾಸಣೆ ಮುಗಿಸಿ, NAT ಮಾಲೀಕನ ಸಹಾಯದಿಂದ, Switch ಮೂಲಕ ಮನೆಗೆ ತಲುಪಿ, ಸರಿಯಾದ Port (443) ಕಿಟಕಿಯೊಳಗೆ ಹೋದಾಗ ದೊಡ್ಡಣ್ಣನಿಗೆ ಆ ರಹಸ್ಯ ಪತ್ರ ಸುರಕ್ಷಿತವಾಗಿ ಸಿಗುತ್ತದೆ!
