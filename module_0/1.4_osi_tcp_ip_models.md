ನಮ್ಮ ರಾಮು ಮತ್ತು ಸೋಮುನ ಮಹಾ ಕಥೆಯನ್ನು ಬಳಸಿಕೊಂಡೇ ಇಡೀ ಕಂಪ್ಯೂಟರ್ ನೆಟ್‌ವರ್ಕಿಂಗ್‌ನ ಜೀವಾಳವಾಗಿರುವ OSI ಮಾಡೆಲ್ (OSI Model) ಮತ್ತು TCP/IP ಮಾಡೆಲ್ ಅನ್ನು ಅತ್ಯಂತ ಸರಳವಾಗಿ ತಿಳಿಯೋಣ!
ಇಷ್ಟು ದಿನ ನಾವು ಕಲಿತ ಕಥೆಯಲ್ಲಿ, ರಾಮು ಪತ್ರ ಬರೆಯುವುದರಿಂದ ಹಿಡಿದು ಅದು ಸೋಮುನ ಕೈ ಸೇರುವವರೆಗೆ ಬೇರೆ ಬೇರೆ ಹಂತಗಳಲ್ಲಿ ಬೇರೆ ಬೇರೆ ಅಧಿಕಾರಿಗಳು ಕೆಲಸ ಮಾಡಿದ್ದನ್ನು ನೋಡಿದ್ದೇವಲ್ಲವೇ? ಈ ಇಡೀ ವ್ಯವಸ್ಥೆಯನ್ನು ಅಚ್ಚುಕಟ್ಟಾಗಿ ನಡೆಸಲು ಜಗತ್ತಿನ ಎಲ್ಲಾ ಕಂಪ್ಯೂಟರ್‌ಗಳು ಒಪ್ಪಿಕೊಂಡಿರುವ ಒಂದು ವ್ಯವಸ್ಥಿತ ನಿಯಮಾವಳಿಯೇ OSI ಮಾಡೆಲ್ (ಇದು 7 ಅಂತಸ್ತುಗಳ ಒಂದು ದೊಡ್ಡ ಕಚೇರಿಯಂತೆ) ಮತ್ತು ಅದರ ಆಧುನಿಕ ರೂಪವೇ TCP/IP ಮಾಡೆಲ್ (ಇದು 4 ಅಂತಸ್ತುಗಳ ಕಚೇರಿ).
------------------------------
## ೧. ಒಎಸ್ಐ ಮಾಡೆಲ್ (OSI Model - 7 Layers)
ನೆಟ್‌ವರ್ಕ್ ಜಗತ್ತಿನಲ್ಲಿ ಡೇಟಾ ಹೇಗೆ ಪ್ರಯಾಣ ಮಾಡುತ್ತದೆ ಎಂದು ವಿವರಿಸಲು ಜಗತ್ತು 7 ಲೇಯರ್‌ಗಳ (ಅಂತಸ್ತುಗಳ) ಈ ಕಚೇರಿಯನ್ನು ಬಳಸುತ್ತದೆ. ಮೇಲಿನ ಅಂತಸ್ತಿನಿಂದ ಕೆಳಗಿನ ಅಂತಸ್ತಿನವರೆಗೆ ಪತ್ರ ಹೇಗೆ ಸಾಗುತ್ತದೆ ಎಂದು ನೋಡೋಣ:

* 7. ಅಪ್ಲಿಕೇಶನ್ ಲೇಯರ್ (Application Layer): ಇದು ಕಥೆಯ ಆರಂಭ. ರಾಮು ಸೋಮುಗೆ ಗೇಮ್ ಆಡಲು ಸಂದೇಶ ಬರೆಯಲು ಬಳಸುವ ಜಾಗ. ಇಂಟರ್ನೆಟ್ ಲೋಕದಲ್ಲಿ ಇದು HTTP/HTTPS ಅಥವಾ ನಿಮ್ಮ ವಾಟ್ಸಾಪ್ ಅಪ್ಲಿಕೇಶನ್ ಇದ್ದಂತೆ.
* 6. ಪ್ರೆಸೆಂಟೇಶನ್ ಲೇಯರ್ (Presentation Layer): ರಾಮು ಬರೆದ ಪತ್ರವನ್ನು ಬೇರೆಯವರು ಕದಿಯದಂತೆ ರಹಸ್ಯ ಭಾಷೆಗೆ ಬದಲಾಯಿಸುವ (Encryption) ಜಾಗ. ಡೇಟಾ ಯಾವ ರೂಪದಲ್ಲಿರಬೇಕು ಎಂದು ಇದು ನಿರ್ಧರಿಸುತ್ತದೆ.
* 5. ಸೆಷನ್ ಲೇಯರ್ (Session Layer): ರಾಮು ಮತ್ತು ಸೋಮು ನಡುವೆ ಮಾತುಕತೆ ಆರಂಭವಾಗುವ ಮುನ್ನ ಇಬ್ಬರ ನಡುವೆ ಒಂದು ಸಂಪರ್ಕದ ಸಮಯವನ್ನು (Session) ನಿಗದಿಪಡಿಸುವ ವ್ಯವಸ್ಥಾಪಕ.
* 4. ಟ್ರಾನ್ಸ್‌ಪೋರ್ಟ್ ಲೇಯರ್ (Transport Layer): ಇಲ್ಲಿಗೆ ನಮ್ಮ ಜವಾಬ್ದಾರಿಯುತ ಅಂಗರಕ್ಷಕ TCP ಅಥವಾ ವೇಗದ ಅಂಗರಕ್ಷಕ UDP ಬರುತ್ತಾರೆ! ಇವರು ಪತ್ರಕ್ಕೆ ಕಿಟಕಿ ಸಂಖ್ಯೆಯನ್ನು (Port Number) ಅಂಟಿಸಿ, ಸುರಕ್ಷಿತವಾಗಿ ಸಾಗಿಸುವ ಜವಾಬ್ದಾರಿ ತಗೋತಾರೆ.
* 3. ನೆಟ್‌ವರ್ಕ್ ಲೇಯರ್ (Network Layer): ಇಲ್ಲಿಗೆ ನಮ್ಮ ಅಂಚೆ ಅಧಿಕಾರಿ ರೌಟರ್ (Router) ಬರುತ್ತಾನೆ. ಇವನು ಪತ್ರದ ಮೇಲೆ IP Address ಬರೆದು, ಹಳ್ಳಿಯ ಗೇಟ್ ದಾಟಿಸಿ (Default Gateway), ಬೆಂಗಳೂರಿಗೆ ಹೋಗಲು ಅತ್ಯುತ್ತಮ ದಾರಿ ಹುಡುಕುತ್ತಾನೆ (Routing). ಇಲ್ಲಿ ಪತ್ರವನ್ನು Packet ಎನ್ನಲಾಗುತ್ತದೆ.
* 2. ಡೇಟಾ ಲಿಂಕ್ ಲೇಯರ್ (Data Link Layer): ಇಲ್ಲಿ ಲೋಕಲ್ ಪೋಸ್ಟ್‌ಮ್ಯಾನ್ ಸ್ವಿಚ್ (Switch) ಕೆಲಸ ಮಾಡುತ್ತಾನೆ. ಇವನು ಪ್ಯಾಕೆಟ್‌ಗೆ ಕವರ್ ಹಾಕಿ, ಸೀಲ್ ಒತ್ತಿ (Frame), ಅದರ ಮೇಲೆ ಮನೆಯೊಳಗಿನ ಮುಖ ಪರಿಚಯದ ವಿಳಾಸವನ್ನು (MAC Address) ಬರೆಯುತ್ತಾನೆ.
* 1. ಫಿಸಿಕಲ್ ಲೇಯರ್ (Physical Layer): ಇದು ಕೊನೆಯ ಹಂತ. ಕವರ್ ಸಿದ್ಧವಾದ ಮೇಲೆ ಅಂಚೆಯಣ್ಣ ರಸ್ತೆಯ ಮೂಲಕ (ವೈರ್ ಅಥವಾ ವೈ-ಫೈ ತರಂಗಗಳ ಮೂಲಕ - Bits 0 and 1) ಭೌತಿಕವಾಗಿ ಪ್ರಯಾಣ ಮಾಡುವ ಹಾದಿ.

------------------------------
## ೨. ಟಿಸಿಪಿ/ಐಪಿ ಮಾಡೆಲ್ (TCP/IP Model - 4 Layers)
OSI ಮಾಡೆಲ್ ಕೇವಲ ಪುಸ್ತಕದಲ್ಲಿ ಕಲಿಯಲು ಚೆನ್ನಾಗಿದೆ (Theoretical). ಆದರೆ ಇಂದಿನ ಇಂಟರ್ನೆಟ್ ಜಗತ್ತು ನಿಜವಾಗಿ ಕೆಲಸ ಮಾಡುವುದು TCP/IP ಮಾಡೆಲ್ ಆಧಾರದ ಮೇಲೆ. ಇದು OSI ಮಾಡೆಲ್‌ನ ೭ ಅಂತಸ್ತುಗಳನ್ನು ಒಟ್ಟುಗೂಡಿಸಿ ಸರಳವಾದ ೪ ಅಂತಸ್ತುಗಳ (Layers) ಕಚೇರಿಯನ್ನಾಗಿ ಮಾಡಿದೆ:

* 1. ಅಪ್ಲಿಕೇಶನ್ ಲೇಯರ್ (Application Layer): ಇದು OSI ಮಾಡೆಲ್‌ನ ಮೇಲಿನ ಮೂರು ಲೇಯರ್‌ಗಳನ್ನು (Application, Presentation, Session) ಒಂದೇ ಮಾಡಿದೆ. ರಾಮು ಸಂದೇಶ ಬರೆಯುವುದು, ಅದಕ್ಕೆ ರಹಸ್ಯ ಕೋಡ್ ಹಾಕುವುದು (HTTPS), ಮತ್ತು DNS ಅಜ್ಜನ ಸಹಾಯದಿಂದ ಐಪಿ ಹುಡುಕುವುದು ಎಲ್ಲವೂ ಇಲ್ಲೇ ನಡೆದುಹೋಗುತ್ತದೆ.
* 2. ಟ್ರಾನ್ಸ್‌ಪೋರ್ಟ್ ಲೇಯರ್ (Transport Layer): ಇದು OSI ಮಾಡೆಲ್‌ನಷ್ಟೇ ಕೆಲಸ ಮಾಡುತ್ತದೆ. TCP ಮತ್ತು UDP ಅಂಗರಕ್ಷಕರು ಪೋರ್ಟ್ ಸಂಖ್ಯೆಗಳನ್ನು (Ports) ನಿರ್ವಹಿಸುವ ಜಾಗ.
* 3. ಇಂಟರ್ನೆಟ್ ಲೇಯರ್ (Internet Layer): ಇದು OSI ಮಾಡೆಲ್‌ನ ನೆಟ್‌ವರ್ಕ್ ಲೇಯರ್‌ನಂತೆ. IP Address, Router, Routing ಮತ್ತು ಹಳ್ಳಿಯ ದೊಡ್ಡ ಗೇಟ್ ಆದ Default Gateway ಎಲ್ಲವೂ ಈ ಅಂತಸ್ತಿನಲ್ಲೇ ಬರುತ್ತವೆ.
* 4. ನೆಟ್‌ವರ್ಕ್ ಆಕ್ಸೆಸ್ ಲೇಯರ್ (Network Access Layer): ಇದು OSI ಮಾಡೆಲ್‌ನ ಕೊನೆಯ ಎರಡು ಲೇಯರ್‌ಗಳನ್ನು (Data Link, Physical) ಒಂದಾಗಿಸಿದೆ. ಅಂದರೆ ಕವರ್ ಹಾಕುವುದು (Frame), ಮುಖ ಪರಿಚಯದ ವಿಳಾಸ ಬರೆಯುವುದು (MAC Address), Switch ಮೂಲಕ ಹಂಚುವುದು ಮತ್ತು ವೈರ್ ಅಥವಾ ವೈ-ಫೈ ಮೂಲಕ ಡೇಟಾ ಹರಿದು ಹೋಗುವುದು ಎಲ್ಲವೂ ಇಲ್ಲೇ ಮುಗಿಯುತ್ತದೆ.

------------------------------
## ನಮ್ಮ ಮಹಾ ಕಥೆಯ ಅಂತಿಮ ಮಹಾ ಸಂಗಮ (The Grand Finale):
ರಾಮು ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಕೂತು ಸಂದೇಶ ಬರೆದಾಗ ಅದು Application Layer ನಲ್ಲಿ ಇರುತ್ತದೆ. ನಂತರ Transport Layer ನಲ್ಲಿ TCP ಅಂಗರಕ್ಷಕ ಅದಕ್ಕೆ ಪೋರ್ಟ್ ನಂಬರ್ ಕೊಡುತ್ತಾನೆ. ಮುಂದೆ Internet Layer ನಲ್ಲಿ Router ಮತ್ತು IP Address ಸಹಾಯದಿಂದ Default Gateway ದಾಟಿ ದಾರಿ ಹುಡುಕಿಕೊಳ್ಳುತ್ತದೆ (Routing). ಕೊನೆಯದಾಗಿ Network Access Layer ನಲ್ಲಿ Frame ಮತ್ತು MAC Address ಪಡೆದು Switch ಹಾಗೂ ಕೇಬಲ್ ಮೂಲಕ ಬೆಂಗಳೂರಿನ ಪಿಜಿಯಲ್ಲಿರುವ ಸೋಮುನ ಕೈ ಸೇರುತ್ತದೆ!
ಇದೇ ಒಟ್ಟಾರೆ ಕಂಪ್ಯೂಟರ್ ನೆಟ್‌ವರ್ಕಿಂಗ್ ಜಗತ್ತು!
