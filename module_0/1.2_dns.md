ನಮ್ಮ ರಾಮು ಮತ್ತು ಸೋಮುನ ಕಥೆಯನ್ನು ಮುಂದುವರಿಸಿ ಇಂಟರ್ನೆಟ್‌ನ ಅತ್ಯಂತ ರೋಮಾಂಚಕ ವಿಷಯವಾದ DNS (Domain Name System) ಬಗ್ಗೆ ಕಥೆಯ ರೂಪದಲ್ಲೇ ತಿಳಿಯೋಣ!
ಈಗ ಸೋಮು ಬೆಂಗಳೂರಿನಲ್ಲಿದ್ದಾನೆ. ರಾಮು ಅವನಿಗೆ ಪತ್ರ ಕಳುಹಿಸಬೇಕಾದರೆ ಸೋಮುನ ಐಪಿ ಅಡ್ರೆಸ್ (IP Address) ಆದ 192.168.1.25 ಅನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳಬೇಕು. ಒಂದು ದಿನ ರಾಮುಗೆ ತನ್ನ ಇನ್ನುಳಿದ ಸ್ನೇಹಿತರಾದ ಭೀಮ, ಅರ್ಜುನ, ನಕುಲ ಹೀಗೆ ಹತ್ತಾರು ಜನರಿಗೂ ಪತ್ರ ಕಳುಹಿಸಬೇಕಾದ ಸಂದರ್ಭ ಬರುತ್ತದೆ.
ಇಲ್ಲಿಗೆ ಒಂದು ಹೊಸ ದೊಡ್ಡ ಸಮಸ್ಯೆ ಶುರುವಾಗುತ್ತದೆ.
------------------------------
## ೧. ಹೊಸ ಸಮಸ್ಯೆ: ಸಂಖ್ಯೆಗಳನ್ನು ನೆನಪಿಡುವುದು ಕಷ್ಟ!
ರಾಮು ತನ್ನ ಎಲ್ಲ ಸ್ನೇಹಿತರ ಐಪಿ ಅಡ್ರೆಸ್‌ಗಳನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳಲು ಪ್ರಯತ್ನಿಸುತ್ತಾನೆ:

* ಸೋಮು ವಿಳಾಸ: 192.168.1.25
* ಭೀಮನ ವಿಳಾಸ: 172.16.254.1
* ಅರ್ಜುನನ ವಿಳಾಸ: 10.0.0.8

ಮಾನವನ ಮೆದುಳಿಗೆ ಇಂತಹ ನೂರಾರು ಜಟಿಲವಾದ ಸಂಖ್ಯೆಗಳನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳುವುದು ತುಂಬಾ ಕಷ್ಟ. ರಾಮು ಒಂದು ಸಂಖ್ಯೆಯನ್ನು ತಪ್ಪು ಬರೆದರೂ ಪತ್ರ ಬೇರೆ ಯಾರದೋ ಮನೆಗೆ ಹೋಗಿ ತಲುಪುತ್ತದೆ! ರಾಮು ಅಂದುಕೊಳ್ಳುತ್ತಾನೆ, "ಛೆ! ಈ ಸಂಖ್ಯೆಗಳ ಬದಲು ಕೇವಲ 'somu.com' ಅಥವಾ 'bhima.com' ಎಂದು ಹೆಸರು ಬರೆದು ಪತ್ರ ಕಳುಹಿಸುವಂತಿದ್ದರೆ ಎಷ್ಟು ಚೆನ್ನಾಗಿರುತ್ತಿತ್ತು!"
ಆದರೆ ನಮಗೆ ಈಗಾಗಲೇ ಗೊತ್ತು, ನಮ್ಮ ಮುಖ್ಯ ಅಂಚೆ ಅಧಿಕಾರಿ ರೌಟರ್‌ಗೆ (Router) ಕೇವಲ ಸಂಖ್ಯೆಗಳು (IP Address) ಮಾತ್ರ ಅರ್ಥವಾಗುತ್ತವೆ, ಹೆಸರುಗಳು ಅರ್ಥವಾಗುವುದಿಲ್ಲ.
------------------------------
## ೨. ರಕ್ಷಕನಾಗಿ ಬಂದ "DNS" ಅಜ್ಜ (The Phonebook Creator)
ಈ ಗೊಂದಲವನ್ನು ಪರಿಹರಿಸಲು ಹಳ್ಳಿಯ ಅಂಚೆ ಕಚೇರಿಯಲ್ಲಿ ಒಬ್ಬ ವಯಸ್ಸಾದ, ಜ್ಞಾನಿ ಅಜ್ಜ ಕುಳಿತಿರುತ್ತಾರೆ. ಆ ಅಜ್ಜನ ಹೆಸರೇ DNS (Domain Name System).
ಈ ಅಜ್ಜನ ಹತ್ತಿರ ಒಂದು ದಪ್ಪನಾದ, ಪ್ರಪಂಚದ ಎಲ್ಲಾ ಜನರ ಹೆಸರು ಮತ್ತು ಅವರ ಐಪಿ ಅಡ್ರೆಸ್ ಇರುವ ಒಂದು ಮಹಾ ಫೋನ್‌ಬುಕ್ (Directory) ಇರುತ್ತದೆ.
ಈಗ ರಾಮುಗೆ ಸೋಮುನ ಐಪಿ ಅಡ್ರೆಸ್ ಮರೆತುಹೋದರೆ ಅವನು ಚಿಂತೆ ಮಾಡುವುದಿಲ್ಲ. ಅವನು ಕವರಿನ ಮೇಲೆ ಸರಳವಾಗಿ "ಸೋಮು (somu.com)" ಎಂದು ಬರೆದು ನೇರವಾಗಿ DNS ಅಜ್ಜನ ಹತ್ತಿರ ಹೋಗುತ್ತಾನೆ.

* ರಾಮು: "ಅಜ್ಜ, ನನಗೆ ಸೋಮುನ ಐಪಿ ಅಡ್ರೆಸ್ ಮರೆತುಹೋಗಿದೆ, ಜರಾ ನಿನ್ನ ಫೋನ್‌ಬುಕ್ ನೋಡಿ ಹೇಳು."
* DNS ಅಜ್ಜ: (ತನ್ನ ದೊಡ್ಡ ಡೈರಿ ಪುಟ ತಿರುವಿ ನೋಡಿ) "ಹಾ ಸಿಕ್ಕಿತು! ಸೋಮು ಅಂದರೆ ಅವನ ಐಪಿ ಅಡ್ರೆಸ್ 192.168.1.25 ಬರೆದುಕೋ ಮಗನೇ."

DNS ಅಜ್ಜ ತಕ್ಷಣ ಆ ಹೆಸರನ್ನು ಸಂಖ್ಯೆಯಾಗಿ ಬದಲಾಯಿಸಿಕೊಡುತ್ತಾನೆ (Domain Name to IP Resolution). ಈಗ ರಾಮು ಆ ಐಪಿ ಅಡ್ರೆಸ್ ಅನ್ನು ಕವರಿನ ಮೇಲೆ ಬರೆದು ರೌಟರ್ ಕೈಗೆ ಕೊಡುತ್ತಾನೆ. ರೌಟರ್ ಎಂದಿನಂತೆ ಪತ್ರವನ್ನು ಬೆಂಗಳೂರಿಗೆ ತಲುಪಿಸುತ್ತದೆ.
------------------------------
## ಕಂಪ್ಯೂಟರ್ ಭಾಷೆಯಲ್ಲಿ ಇದರ ಅರ್ಥವೇನು?
ನಾವು ದಿನಾ ಇಂಟರ್ನೆಟ್ ಬಳಸುವಾಗ ಗೂಗಲ್ ನೋಡಲು google.com ಅಥವಾ ಯೂಟ್ಯೂಬ್ ನೋಡಲು youtube.com ಎಂದು ಟೈಪ್ ಮಾಡುತ್ತೇವೆ. ಇವುಗಳನ್ನು ಡೊಮೈನ್ ನೇಮ್ (Domain Name) ಎನ್ನುತ್ತಾರೆ. ಆದರೆ ಕಂಪ್ಯೂಟರ್‌ಗಳಿಗೆ ಈ ಹೆಸರುಗಳು ಅರ್ಥವಾಗುವುದಿಲ್ಲ, ಅವುಗಳಿಗೆ ಕೇವಲ ಐಪಿ ಅಡ್ರೆಸ್ (ಉದಾಹರಣೆಗೆ: 142.250.190.46) ಮಾತ್ರ ಗೊತ್ತು.
ನಾವು ಬ್ರೌಸರ್‌ನಲ್ಲಿ google.com ಎಂದು ಟೈಪ್ ಮಾಡಿದ ತಕ್ಷಣ, ನಮ್ಮ ಮೊಬೈಲ್ ಮೊದಲು ಇಂಟರ್ನೆಟ್‌ನಲ್ಲಿರುವ DNS ಸರ್ವರ್ ಹತ್ತಿರ ಓಡುತ್ತದೆ. "ಗೂಗಲ್‌ನ ಐಪಿ ಅಡ್ರೆಸ್ ಏನು?" ಎಂದು ಕೇಳುತ್ತದೆ. DNS ಸರ್ವರ್ ತಕ್ಷಣ ತನ್ನ ಫೋನ್‌ಬುಕ್ ನೋಡಿ ಐಪಿ ಅಡ್ರೆಸ್ ಅನ್ನು ವಾಪಸ್ ನೀಡುತ್ತದೆ. ಆ ಐಪಿ ಅಡ್ರೆಸ್ ಬಳಸಿ ನಮ್ಮ ಮೊಬೈಲ್ ಗೂಗಲ್ ವೆಬ್‌ಸೈಟ್ ಅನ್ನು ಓಪನ್ ಮಾಡುತ್ತದೆ. ಈ ಇಡೀ ಪ್ರಕ್ರಿಯೆ ಕೇವಲ ಒಂದು ಸೆಕೆಂಡ್‌ನ ನೂರನೇ ಒಂದು ಭಾಗದಲ್ಲಿ (Milliseconds) ನಡೆದುಹೋಗುತ್ತದೆ!
------------------------------
## ನಮ್ಮ ಮಹಾ ಕಥೆಯ ಅಂತಿಮ ಚಿತ್ರಣ (Complete Summary with DNS):
ರಾಮು somu.com ಎಂದು ಬರೆದಾಗ, ಮೊದಲು DNS ಅಜ್ಜ ಅದರ ಅಸಲಿ ವಿಳಾಸ 192.168.1.25 ಎಂದು ಹುಡುಕಿಕೊಡುತ್ತಾನೆ. ನಂತರ ಆ ಪತ್ರಕ್ಕೆ HTTPS ಸೈನಿಕ ರಹಸ್ಯ ಬೀಗ ಹಾಕುತ್ತಾನೆ, TCP ಅಂಗರಕ್ಷಕ ಜವಾಬ್ದಾರಿ ತಗೋತಾನೆ, ಕವರಿನೊಳಗೆ ಸೇರಿ (Frame), Router ನಿರ್ಧರಿಸಿದ ದಾರಿಯಲ್ಲಿ (Routing), Firewall ಕಾವಲು ದಾಟಿ, NAT ಮಾಲೀಕನ ಸಹಾಯದಿಂದ, Switch ಮೂಲಕ ಮನೆ ತಲುಪಿ, ಸರಿಯಾದ Port ಕಿಟಕಿಯೊಳಗೆ ಸೋಮುನ ಕೈ ಸೇರುತ್ತದೆ!
